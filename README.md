# Rootwork Task Manager

## 1. What the Program Does

The Rootwork Task Manager is a JavaScript program that helps organise and track tasks. Each task has a title, category, completion status, and priority level.

The program displays task details, calculates the total number of tasks, counts completed and pending tasks, identifies high-priority pending tasks, counts tasks by category, and allows new tasks to be added.

## 2. How I Broke Down the Problem

I divided the project into smaller tasks:

- Created an array to store task objects.
- Used a loop to display the details of each task.
- Used counters to calculate completed and pending tasks.
- Used conditional statements to identify high-priority pending tasks.
- Counted tasks belonging to different categories.
- Created functions to organise reusable operations.
- Created a way to add new tasks to the list.

Breaking the project into smaller parts made it easier to understand, build, and test.

## 3. JavaScript Concepts Used

- **Arrays:** Used to store multiple tasks.
- **Objects:** Used to store each task's properties.
- **Variables:** Used to store task data and counting results.
- **Loops:** Used to go through the task list.
- **Conditional statements:** Used to check task status and priority.
- **Functions:** Used to organise and reuse code.
- **Boolean values:** Used to represent whether a task is completed.
- **Array methods:** Used where applicable to manage task data.

## 4. The Hardest Part

The most challenging part was understanding how conditions and functions work together. I learned that a small change to a condition can affect which tasks the program displays. I also learned that `console.log()` prints a message, while a function can perform several operations, such as calculating and displaying statistics.

## 5. One Improvement I Would Make

I would improve the program by allowing users to enter new tasks interactively and save tasks so they remain available after the program closes.
